Issue #13 calls for a full modernization of the library. This changes the package to a deliberate 2.0.0 release: Debug keeps its established API, while obsolete public test/error helpers and incorrect Ajax resolution semantics are removed.

## Resulting behavior

- Debug and Disable import and initialize safely in Node.js and SSR.
- `Debug.trace()` calls `console.trace`; URL-wide activation works with repeated parameters.
- Ajax uses native Fetch, forwards request options and AbortSignal, parses JSON or text, handles empty bodies, and rejects HTTP/network/parse failures.
- ESM runs directly with explicit specifiers; esbuild creates reliable CommonJS output.
- The package has zero runtime dependencies and ships 28 runtime files (about 12 kB compressed).
- Node.js 22+ is the supported runtime.

## Tooling and infrastructure

- Replaced Jest, SWC, jsdom-based tests, raw loading, and handwritten regex module conversion.
- Added native `node:test` coverage and packed-output tests.
- Replaced Travis CI with GitHub Actions on Node.js 22 and 24.
- Added Vite, Next.js, and native-browser consumer fixtures.
- Added durable repository instructions, modernization progress, changelog, and 1.x migration guidance.

## Breaking changes

- Removed the root `Tests` namespace and `@flippydisk/tools/tests`.
- Removed `Json.promise`, `Json.responder`, and their subpaths.
- Ajax failures now reject rather than resolving error-shaped values.
- Node.js 22 or newer is required.

## Validation

- `npm run check`
- 17 unit/regression tests; 97.73% line and 93.04% branch coverage
- ESM and CommonJS root/subpath artifact tests
- Actual packed tarball installed in an isolated consumer
- Native Chrome import of real `dist/esm` output
- Vite 7 production build
- Next.js 16 production build, including server-side Debug construction
- `npm audit`: zero known vulnerabilities
- `npm pack --dry-run`: 28 files, about 12 kB compressed

No package was published, no release tag was created, and this draft PR has not been merged.
